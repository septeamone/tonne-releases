# Tonne

Installers and updates for Tonne. Download the latest **Tonne_*_x64-setup.exe** from [Releases](https://github.com/septeamone/tonne-releases/releases/latest). Installed copies update themselves with the «Обновить» button.

Установщики и обновления Tonne. Скачай последний **Tonne_*_x64-setup.exe** в [Releases](https://github.com/septeamone/tonne-releases/releases/latest). Установленная программа обновляется сама кнопкой «Обновить».
